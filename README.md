# Panhandle Gunslingers Sidebar

GitHub Pages-ready sidebar for the Chess.com club `panhandle-gunslingers`.

## Files
- `index.html` — sidebar page
- `assets/panhandle-logo.png` — club logo
- `assets/most-wanted-new-members.png` — transparent new-member board
- `assets/gunslinger-duel.png` — transparent duel artwork

## Deploy
Upload the contents of this folder to the root of a GitHub repository and enable GitHub Pages from the main branch/root folder.

The five newest members are pulled client-side from Chess.com's public club-members endpoint and sorted by the API's join timestamp. Player profile calls are used to populate avatars where available.
